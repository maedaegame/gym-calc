# Plate Loader

A tiny one-page tool for plate-loaded gym machines. Tap the plates you put on **one side**; it shows the real total (both sides), plus the plates per side for **50%** and **80%** of that weight.

Plates: 2.5, 5, 10, 25, 35, 45 lb. Your last load is saved in your browser.

## Use it on your phone (GitHub Pages)

1. Create a new repo and upload `index.html` (and this README).
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, then Save.
3. After a minute, open `https://<your-username>.github.io/<repo-name>/`.
4. On your phone, use **Add to Home Screen** so it opens like an app.
